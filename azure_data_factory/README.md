# Azure Data Factory

This section of the repository contains **hands-on projects built with Azure Data Factory**, focused on hybrid data integration, orchestration, and cloud ingestion scenarios.

Each project demonstrates how Azure Data Factory can connect on-premises and cloud data sources, orchestrate metadata-driven workflows, perform full and incremental ingestion, and integrate with services such as **Azure Data Lake Storage Gen2**, **Azure Databricks**, and **Azure SQL Database**.

## Technologies involved

* Azure Data Factory
* Self-hosted Integration Runtime
* Azure Data Lake Storage Gen2 (ADLS)
* Azure Databricks / PySpark
* Azure SQL Database
* Oracle
* SQL Server
* Parquet / Delta
* Azure Key Vault

## 🧠 Learning Focus

* Hybrid on-premises to Azure data integration.
* Metadata-driven pipeline design and orchestration.
* Full and incremental ingestion patterns.
* Self-hosted Integration Runtime configuration.
* Landing and staging data in ADLS.
* Orchestrating external processing with Azure Databricks.
* Publishing trusted data to relational serving layers.
* Error handling, rerun control, monitoring, and execution traceability.
* Secure credential management with Azure Key Vault.
